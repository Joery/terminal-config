# terminal-config
Windows Terminal configuration focused on styling & extra profiles.

## Getting Started
1. Open **Windows Terminal**.
2. Click the dropdown arrow next to the new tab button and select **Settings**.
3. Click **Open JSON file** in the bottom-left corner.
4. Replace the contents of the file with those from [settings.json](settings.json) in this repository.
5. Save the file to apply the settings.
